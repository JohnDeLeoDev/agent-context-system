# Agent context

Use get_session_context at startup and MCP tools for context reads and writes. Global rules apply everywhere; workspace and project rules add scoped instructions. Keep content in the store and generate only the files harnesses require.

Hooks and scripts are indexed from their metadata sidecars. home-settings-sync owns the event registry; harness-materialize renders consumers. Configure optional hooks in global/starter-config.json and services in global/mcp-servers.json.

Record your own architecture decisions here. This starter has no existing projects, fleet, remotes or personal memories.
