# Machine setup

Install the starter at ~/.agent-context using setup.py. Select installed harnesses, review the global rules and hook profile, and register the machine through MCP. Local setup creates loopback-scoped owner credentials; provision separate scoped credentials and a TLS endpoint for remote relays. Configure your own git identity, signing, remotes, dependency roles, LSP canaries and optional notification backend. No dotfiles manager or notification provider is required by this starter.
